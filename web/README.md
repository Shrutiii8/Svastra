# Svastra Web — Landing Page & Digital Twin Simulator

Official website for **Svastra (HeatGuard Twin)** — Wearable-powered heat-exposure physiological digital twin monitoring for outdoor workers.

## Features
- **Design System**: Matches the Svastra mobile app tokens (Deep Midnight Navy, Electric Blue, Cyan, Glassmorphism) with Dark & Light theme toggling.
- **How It Works**: Explains the 4-stage pipeline: Wearable Telemetry Sync, Hyper-Local Microclimate Ingestion, Personal Baseline Normalization, and Deterministic Clinical Rule Engine.
- **Interactive Twin Simulator**: Real-time interactive sandbox letting visitors adjust ambient temperature, heart rate, and worker baselines with live strain calculations and safety protocols.
- **Core Industry Profiles**: Tailored safety context for Construction, Delivery Fleets, Street Vendors, and Traffic Police.
- **Team**: Anupam Raj (Lead Architect & Fullstack Systems), Shruti Sinha (Mobile & Wearable Health Lead), Sanskar Agarwal (Data Modeling & Biometric Analytics).
- **Working Contact Form**: Functional inquiry submission connecting to `contact@svastra.com`.

## Local Preview
Open `index.html` in any web browser or start a lightweight server:
```bash
python3 -m http.server 3000
```
Then navigate to `http://localhost:3000`.
